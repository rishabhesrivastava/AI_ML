# Intelligent Book Recommendation System - Approach 3

## Overview
This is Approach 3 of the Book Recommendation System implementation, which uses a **single Jupyter Notebook** that **automatically generates a Streamlit application file**. This combines the compactness of a single notebook with the professional web interface of Streamlit.

## Structure
- `2025AIML049.ipynb` - Complete ML pipeline with auto-generated Streamlit app
- `requirements.txt` - Python dependencies
- `Goodreadss Books.csv` - Original dataset
- `cleaned_books.csv` - Preprocessed dataset (generated after running notebook)
- `tfidf_vectorizer.pkl` - Saved TF-IDF vectorizer (generated after running notebook)
- `cosine_similarity_matrix.pkl` - Saved similarity matrix (generated after running notebook)
- `book_titles.pkl` - Saved book titles (generated after running notebook)
- `app.py` - Streamlit application (auto-generated by notebook)

## How to Run

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the Jupyter Notebook
```bash
jupyter notebook 2025AIML049.ipynb
```
- Run all cells to perform data cleaning, EDA, feature extraction, and model training
- The notebook will automatically generate the `app.py` file
- This will create: `cleaned_books.csv`, `tfidf_vectorizer.pkl`, `cosine_similarity_matrix.pkl`, `book_titles.pkl`, `app.py`

### Step 3: Run the Streamlit App
```bash
streamlit run app.py
```
- The app will open in your browser at http://localhost:8501
- Search for books and get recommendations

**Alternatively**, run the last cell in the notebook with `!streamlit run app.py` to launch directly from the notebook.

## Technical Details
- **Algorithm**: Content-Based Filtering
- **Similarity Metric**: Cosine Similarity
- **Feature Extraction**: TF-IDF (5000 features)
- **Dataset**: 20,069 books from Goodreads
- **Text Processing**: NLTK for tokenization, stopword removal, lemmatization
- **UI Framework**: Streamlit (auto-generated from notebook)

## How the Auto-Generation Works
1. The notebook contains the complete ML pipeline
2. The last section contains the Streamlit app code as a Python string
3. When you run that cell, it writes the Streamlit app to `app.py`
4. You can then run `streamlit run app.py` to launch the web interface
5. All models and data are saved during notebook execution and loaded by the Streamlit app
